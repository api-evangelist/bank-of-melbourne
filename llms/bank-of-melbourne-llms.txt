# Bank of Melbourne

> Bank of Melbourne is a Victorian retail and business banking brand operated by Westpac Banking Corporation (ASX: WBC), running under the St.George Bank banking authority within the Westpac Group — not a customer-owned mutual. As an accredited Consumer Data Right (CDR) data holder it exposes a public, unauthenticated Product Reference Data (PRD) API conforming to the DSB Consumer Data Standards. This is the only public API surface; consumer/account data sharing runs through the CDR Accredited Data Recipient consent model, not a public developer portal.

## APIs

- [Bank of Melbourne CDR Product Reference Data API](https://www.bankofmelbourne.com.au/online-services/open-banking): Public, unauthenticated banking product catalogue (rates, fees, features, eligibility) under Australia's CDR. Base URL https://digital-api.bankofmelbourne.com.au/cds-au/v1 ; send header x-v: 5. Two public operations: Get Products (listBankingProducts) and Get Product Detail (getBankingProductDetail). Confirmed live: x-v 5 -> 200, meta.totalRecords 40; x-v 3 -> 406.
